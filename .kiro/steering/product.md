# プロダクト概要

このプロジェクトは、GomaGoma676 氏による「Next.js + Hasura」チュートリアルをベースとした学習プロジェクトです。リアルタイムデータ管理機能を持つフルスタック GraphQL アプリケーションを実演しています。

## 主要機能

- **ユーザー管理**: ユーザーエンティティの CRUD 操作
- **リアルタイムデータ**: Hasura による GraphQL サブスクリプションとクエリ
- **複数のデータ取得パターン**: Apollo Client の様々なフェッチポリシーの実演
- **静的生成**: SSG と ISR の実装例
- **状態管理**: Apollo Client リアクティブ変数によるローカル状態管理

## 目的

このプロジェクトは、モダンな React パターン、GraphQL 統合、Next.js 機能の学習に焦点を当てた教育用コードベースです。Next.js フロントエンドと Hasura GraphQL バックエンドを接続する実践的な例として機能します。

## 本番環境

- **フロントエンド**: Vercel にデプロイ
- **バックエンド**: Heroku PostgreSQL データベースを使用した Hasura Cloud
- **ダッシュボード**: データ管理用の Hasura Cloud コンソールで利用可能
